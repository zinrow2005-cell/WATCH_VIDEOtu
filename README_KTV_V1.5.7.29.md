# KTV V1.5.7.29 — 攝影機來源與流暢度修正版

完整網站程式碼包含 index.html、app.js、ktv-studio.js、CSS、PWA 與資源檔。將 ZIP 解壓縮內容放到 GitHub Pages 儲存庫根目錄。

## 變更
- KTV 鏡頭新增「攝影機來源與流暢度」折疊區：可選裝置、解析度及影格率，重新開鏡頭套用。
- 取得攝影機實際解析度與瀏覽器回報的 frameRate。
- 一般鏡頭預覽關閉非必要 CSS 模糊、陰影與動畫；AI 去背仍使用原有處理。
- 避免重複點擊同時開啟多個相機流程。
- PWA 版本快取同步。

## 重要限制
純攝影機診斷頁也卡頓，顯示問題可能源自攝影機驅動／USB／瀏覽器解碼或硬體輸出，網頁程式無法保證消除。請在 Windows 相機應用程式測試，並比較 640×480 15fps 與 30fps。

## 測試方式
關閉其他正在使用攝影機的程式與分頁，重新開啟 KTV，先關閉去背與錄影，再依序測試 640×480 30fps、15fps、320×240 30fps，記錄哪個流暢。
