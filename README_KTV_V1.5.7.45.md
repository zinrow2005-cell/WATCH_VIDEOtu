# V1.5.7.46｜手機鏡頭、錄影停止與歌詞修復

- 手機「純自拍鏡頭」直接錄製攝影機影像軌，減少 Safari Canvas 影像擷取黑屏與空檔的風險。
- iOS 鏡頭啟動使用 facingMode:user，不強制桌面 1280×720 參數；電腦維持原設定。
- 錄製停止時釋放影像、麥克風、畫面合成串流；手機同時關閉鏡頭。
- 假如瀏覽器仍沒有輸出影片資料，顯示錄後視窗與歌詞按鈕，清楚告知不能播放。
- 歌詞沿用依歌曲名稱自動查詢，僅在手機／平板錄後檢視。
- 注意：預設背景／相簿背景仍須 Canvas 合成，部分 iOS/Safari 版本可能不支援有效錄製；建議先測試「純自拍鏡頭」。
- 本版經靜態驗證，尚未完成真實 iPhone 的錄影與解碼測試。
