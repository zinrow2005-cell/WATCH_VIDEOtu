# WATCH_VIDEOtu V1.5.7.42｜電腦分頁錄影鏡頭閃爍改善

- 電腦錄製 KTV Chrome 分頁時直接使用 `getDisplayMedia()` 提供的原生畫面軌，取消二次 Canvas 繪製與 20fps 再擷取。
- 已顯示在 KTV 分頁的自拍鏡頭會隨分頁影像錄入，不另外重複疊上人物。
- 錄影期間關閉鏡頭預覽的 CSS 動畫、濾鏡、陰影與過渡；結束錄影立即還原。
- 手機／平板的預設背景、相簿照片、錄音與本機儲存方式維持原有流程。
- 保留攝影機 1280×720／30fps 設定。
- 注意：Chrome 仍必須授權擷取目前 KTV 分頁，並勾選分頁音訊；錄影仍儲存到本機，不會上傳 GitHub。
- 這是程式層修正，尚未實機驗證特定電腦攝影機的閃爍是否消失。
