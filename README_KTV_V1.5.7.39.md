# WATCH_VIDEOtu V1.5.7.39 — KTV 簡易錄影重設版

此版移除舊版 KTV 錄影工作室（ktv-studio.js/css）、複雜混音、錄前檢測及重複的手機/電腦控制按鈕。

## 操作
1. 選一首 KTV 歌曲。
2. 點「開啟鏡頭」；也可直接點「開始錄影」自動請求相機與麥克風。
3. 「設定」可以選影片／純人聲錄音、預設背景／照片／自拍／電腦分頁、麥克風音量。
4. 點「停止」後預覽與下載；「我的作品」只列出已下載的紀錄，真正影片由瀏覽器下載儲存。

## 限制
- YouTube 嵌入影音在行動瀏覽器無法可靠直接擷取。手機錄影請選自訂背景或預設背景。
- 桌面分享分頁可嘗試取得畫面與分頁聲音，需在分享對話框勾選音訊。
- MP4 輸出取決於瀏覽器 MediaRecorder 支援，否則使用 WebM，並非偽裝副檔名。
- 無自動寫入相簿或跨裝置雲端備份。
- 歌詞搜尋及同步編輯保留獨立工具，但不再綁入錄製流程。
