# WATCH_VIDEOtu V1.5.7.41 — 裝置本機儲存改善

- 不會將錄影、錄音上傳 GitHub；GitHub Pages 僅提供網站程式。
- 電腦：錄製完成後按「選擇資料夾儲存」，Chrome/Edge 支援時呼叫系統「另存新檔」選擇器。若瀏覽器不支援則改用下載。
- 電腦錄 KTV 歌曲與鏡頭需授權「分享目前分頁」並勾選音訊，此為本機瀏覽器畫面擷取權限，並非社群分享或上傳。
- 手機與平板：「儲存至相簿／檔案」使用系統原生分享選單，若影片 MIME 格式／系統不支援，會退回下載；無法保證所有手機直接存進相簿。
- 影片檔案依瀏覽器錄製格式輸出 MP4 或 WebM。
- 原有 KTV 影片、攝影機、音訊選項與相簿背景設定不變。
