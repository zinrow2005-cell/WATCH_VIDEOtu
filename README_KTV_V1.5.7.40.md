# WATCH_VIDEOtu V1.5.7.40 — 裝置分流錄唱版

- 電腦：選擇「KTV 歌曲畫面＋自拍鏡頭」，開始錄影後分享「目前分頁」並啟用音訊。錄製的就是所分享分頁實際顯示的畫面，含鏡頭小視窗；如果未選目前分頁，或分享未勾選音訊，成品不保證有鏡頭／伴奏。
- 手機／平板：提供自拍全畫面、四種預設舞台、相簿照片背景；可先到錄製選項保存照片，再錄製。手機無法可靠錄取 YouTube 畫面或音訊。
- 背景照片儲存於本機 IndexedDB，清除網站資料或無痕模式可能失去設定。
- 保留原有點歌、KTV 播放、鏡頭拖曳、錄製後預覽／下載。
- MP4 是否可以輸出取決於瀏覽器支援的 MediaRecorder MIME 類型，否則使用 WebM。
- 已執行 JavaScript 靜態語法及 ZIP 結構檢查；真實相機、分頁共享與行動設備仍需實機驗證。
