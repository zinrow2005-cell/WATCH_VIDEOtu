# V1.5.7.48 — 本機作品庫與可調鏡頭

- 下載、選擇資料夾儲存，或系統相簿分享成功返回後，將 Blob 同時寫入 IndexedDB「我的作品」。
- 「我的作品」直接播放、下載、刪除；錄影保存在這台裝置此網站的瀏覽器資料裡。若儲存容量不足會提示；若清除瀏覽器網站資料，作品也會消失。
- 鏡頭右下角藍色 ⤡ 可觸控拖曳縮放，亦可在錄製選項調整比例；按住鏡頭其他區域移動位置。
- 電腦分頁錄製的自拍鏡頭大小及位置會出現在分頁擷取內容中。手機使用純自拍模式時直接錄製完整攝影機影像，浮動框尺寸只影響 KTV 畫面的預覽，不會縮小錄製影片裡的人物。
- iOS 的分享選單返回，不一定代表使用者確實選了「儲存影片」，因此只能確認分享呼叫完成，無法由網頁核實照片 App 寫入成功。
