# V1.5.7.38 手機 KTV 操作修復

- 移除與 KTV 主程式衝突的全域捕獲階段按鈕攔截器。
- 快捷按鈕改用 `ktv-studio.js` 單一路徑，避免同一點擊多層轉送。
- 修正手機背景預設為「分享 KTV 分頁」時，錄影前檢查直接停用繼續按鈕的問題。手機可在下一步改用舞台/自訂背景；不會宣稱錄得到 YouTube 音樂。
- 修正攝影機預設 `facingMode` 為非強制的偏好。
- 與 PWA 快取一併升級。

## 操作限制
GitHub Pages 必須透過 HTTPS；首次使用需要授權。手機瀏覽器不支援可靠的 YouTube 分頁影音擷取。尚未經實機攝影機與麥克風端到端驗證。
