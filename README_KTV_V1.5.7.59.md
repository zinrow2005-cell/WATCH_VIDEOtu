# WATCH_VIDEOtu V1.5.7.59

- KTV 播放中的歌曲可直接加入／取消「我的最愛」。
- KTV 新增「播放歷史」和「我的最愛」分頁；歷史記錄保留最近 50 首，可直接試播、點歌或收藏。
- 錄影開始的 Chrome 分頁擷取加入 `suppressLocalAudioPlayback:false` 等音訊限制，嘗試避免擷取時分頁播放音量被壓低。Chrome／Windows 仍可能自行調降音量，網頁無法強制覆寫系統通訊音量設定。若發生此情況，在 Windows「聲音 > 通訊」選「不執行任何動作」，並檢查 Chrome 分頁擷取時的系統音量混音器。
- 切換離開 KTV 時停止攝影機與麥克風；關閉 KTV 播放器時也會停止未在錄製中的鏡頭。正在錄製會先停止封裝。
- 保留 V1.5.7.58 搜尋及原本錄影流程。
