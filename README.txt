FamilyTube V1.1
================

主要新增：
1. 兒童首頁：大分類卡、最近觀看、我的最愛
2. 家長 PIN：可鎖定離開兒童模式、家長設定、新增/刪除影片
3. 觀看時間：不限時 / 15 / 30 / 45 / 60 分鐘，時間到自動暫停
4. 最愛收藏與最近觀看
5. iPad Air 2 橫向版面重新調整
6. 保留 V1.0.1 的 YouTube 錯誤 153 修正

使用方式：
- 請將整個資料夾內容上傳 GitHub Pages。
- 不要直接用 file:// 開 index.html 測試 YouTube。
- 第一次可在家長設定內設定 4~6 位數 PIN。
- PIN 只用來避免小孩誤操作，不是高強度安全機制。

注意：
- YouTube 影片若禁止第三方網站嵌入，仍可能出現 101 / 150，屬影片本身限制。
